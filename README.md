# IT 3203 Web Project Starter

A small static HTML/CSS site for getting started with the course web development environment.

## Open locally

Open `index.html` in a browser, or open this folder in Visual Studio Code and use the Live Preview extension.

## Publish with GitHub Pages

1. In the repository, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)`.
3. Save and use the published URL shown on the Pages settings screen.

This repository is private for now, so it has not been published. GitHub Pages sites are public. The course milestone also asks for at least six pages, consistent navigation, comments in the source, HTML validation, and a ZIP of the source files. This starter is not the completed milestone.

## Files

- `index.html` — starter page and course project note
- `styles.css` — shared responsive styles
