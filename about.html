About this project

A student research project about the protocol behind browser and API communication.

Purpose

This site introduces HTTP and follows its evolution from early web messages to HTTP/2 and HTTP/3. Readers can begin with the foundations, compare versions, review key concepts, follow the source links, and complete a timed self-assessment with question-by-question feedback.

The subject and outline were informed by the supplied HTTP evolution research presentation. Summaries are cross-checked against the linked IETF RFCs, CERN history, MDN guides, and IANA registry.

Class project

This is a class project for IT 3203 Web Development. The pages use HTML for structure, one shared CSS stylesheet for responsive presentation, and JavaScript to run and score the ten-question quiz.

The self-assessment is intended as a study aid. Review the linked standards and resources alongside your own course materials.
